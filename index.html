Flex Courier Monitor

Read-only monitoring for last-mile delivery operations. Application overview.

Status

This application is in development. This page presents it publicly and is also the OAuth 2.0 return address of the application (/callback/). It is an independent project and is not affiliated with, or endorsed by, Mercado Livre.

What it does

It helps a delivery company that operates Mercado Envios Flex with motorcycle couriers to see, in one dashboard, which packages arrived, which courier holds each package and which were delivered, and to calculate the courier payout from those events.

What it reads

Only for Mercado Livre accounts that explicitly authorize the application through OAuth 2.0:

  • Shipment status events (shipments and Flex handshake notifications).
  • The courier assignment of each shipment.

What it does not do

  • It does not create, edit or cancel shipments, listings or orders.
  • It does not sell, rent or share the data it receives.
  • It does not ask for your Mercado Livre password. Sign-in happens on Mercado Livre pages only.

Privacy by design

The application is being built so that access tokens are stored encrypted, data is kept only for as long as the operation needs it, and each connected user can withdraw access at any time from the connected applications settings of their Mercado Livre account. Personal data is handled under Brazilian law (LGPD).

Flex Courier Monitor

Monitoramento somente leitura para operações de entrega de última milha. Apresentação do aplicativo.

Situação

O aplicativo está em desenvolvimento. Esta página o apresenta publicamente e também é o endereço de retorno do OAuth 2.0 (/callback/). É um projeto independente, sem vínculo nem aprovação do Mercado Livre.

O que faz

Ajuda uma empresa de entregas que opera o Mercado Envios Flex com motoboys a ver, em um painel, quais pacotes chegaram, com qual motoboy está cada pacote e quais foram entregues, e a calcular o repasse do motoboy a partir desses eventos.

O que lê

Somente de contas do Mercado Livre que autorizarem o aplicativo de forma explícita por OAuth 2.0:

  • Eventos de status dos envios (shipments e avisos de transferência do Flex).
  • A atribuição do motoboy em cada envio.

O que não faz

  • Não cria, edita nem cancela envios, anúncios ou pedidos.
  • Não vende, aluga nem compartilha os dados que recebe.
  • Não pede a sua senha do Mercado Livre. O login acontece só nas páginas do Mercado Livre.

Privacidade desde o projeto

O aplicativo está sendo construído para guardar os tokens de acesso cifrados, manter os dados só pelo tempo que a operação precisar e permitir que cada usuário conectado retire o acesso a qualquer momento, nas configurações de aplicativos conectados da conta do Mercado Livre. Os dados pessoais seguem a LGPD.
